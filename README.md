# ستشواد
الدخول برمز دعوة مشترك محفوظ كسر INVITE_CODE في الاستضافة. تحقق HMAC عبر ملف Cookie من نوع HttpOnly وSecure على HTTPS وSameSite=Strict، صالح لمدة 180 يومًا. الخروج يمسحه. لا يوجد رمز فردي، واختيار الأسماء يعتمد على ثقة المجموعة. تغيير INVITE_CODE يبطل الجلسات السابقة.

كل لاعب يحدد البداية في سجل settings مستقل start:player-N. الإعداد الجماعي القديم محفوظ لكنه لا يحدد الجداول الشخصية. النتائج السابقة تبقى بتواريخها؛ التسجيل متاح في كل الأيام.

تصدير Excel من الملف الشامل: كل الأشهر أو شهر محدد، ثلاث أوراق، أرقام العدات والثواني منفصلة، وعدد الأيام من النتائج المعتمدة فقط. يسترجع بيانات محدثة قبل التنزيل.

محليًا: npm run dev. يجب تهيئة INVITE_CODE في .dev.vars (ملف غير متتبع)، وتطبيق migrations على قاعدة D1 المحلية. لا تضع رمز الإنتاج في المصدر.
