# همّة
موقع عربي لتحدي تمارين مجموعة أصدقاء، مبني بـ Vinext وReact وقاعدة D1.

## التشغيل
npm install
npm run db:generate
npm run dev

الدخول الحقيقي يعتمد على هوية ChatGPT التي توفرها استضافة Sites؛ المعاينة المحلية تعرض الواجهة دون انتحال حساب.
قاعدة البيانات تحفظ الأعضاء والجولات والجدول. المسودات والمؤقت تحفظ محليًا لكل حساب وتاريخ، ويحدث عرض المجموعة كل 30 ثانية.
أول عضو يضبط البداية يصبح مسؤول الجدول. الحسابات المسموح بها تحدد من صلاحيات Sites.
لا يوجد ربط بنموذج ذكاء اصطناعي حاليًا؛ الرسائل التحفيزية جاهزة ولا تتطلب مفتاح API.
